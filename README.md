# Smart Store India - Premium E-Commerce Platform

A luxurious, high-performance, and meticulously crafted single-page full-stack digital store developed with **React 18**, **TypeScript**, and **Tailwind CSS**. It is fully designed for a seamless shopping experience under a rustic, elegant aesthetic themed with rich forest greens, soft cream tones, and premium high-contrast displays.

---

## 🌟 Key Application Features

### 1. Curated Collections
- Explore and view detailed specs for a premium hand-picked series of analogue wristwatches.
- Aesthetic color swatches, elegant image zoom galleries, and comprehensive specifications.

### 2. Wishlist ("Like") System
- Custom interactive **Heart Button** built onto each product card and product details view.
- Toggles beautiful animations and stores liked preferences persistently in the client's local storage.

### 3. Integrated Cash on Delivery Checkout
- Fully interactive express COD checkout dialog with validation covering major states and districts of India.
- Dynamic automated order generation directly forwarding to WhatsApp for instantaneous confirmation.

### 4. Interactive Customer Reviews
- Write, rate, and submit localized comments for verified product purchases, stored safely across browser lifecycles.

### 5. Highly Polished Celebratory UI Animations
- Rich, high-fidelity custom confetti blast animations, pulsing victory rings, and soft countdown transitions triggered immediately upon checkout completion.

---

## 🛠️ Architecture & Core Dependencies

- **Frontend Core**: React 18, TypeScript, Vite
- **UI & Animations**: `motion` (formerly known as `framer-motion`)
- **Icons Kit**: `lucide-react`
- **Styling Core**: Tailwind CSS Utility design system

---

## 🚀 How to Run Locally

1. **Install dependencies**:
   ```bash
   npm install
   ```

2. **Run development server**:
   ```bash
   npm run dev
   ```

3. **Build the production application**:
   ```bash
   npm run build
   ```

4. **Start production server**:
   ```bash
   npm run start
   ```
